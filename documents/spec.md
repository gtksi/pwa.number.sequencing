# 数字の記憶と操作ゲーム - ワーキングメモリートレーニングアプリ仕様書 (Ver 3.0)

## 1. アプリ仕様 (Application Specifications)

### 1.1 概要
WISC-Vの「数唱（順唱・逆唱）」および「配列（語音整列の数値版）」を基盤とし、視空間認知を最大限に活用するワーキングメモリー（WM）トレーニングアプリ。エラーレス学習と動的難易度調整（DDA）を組み合わせ、記憶容量と実行機能（情報の操作・抑制）を段階的に拡張する。

### 1.2 コアメカニクス（3つのタスクモード）
セッション開始時に以下のいずれかのモードを選択し、1セッション（5〜10分）中はルールを固定する。タスクの混同（認知的干渉）を防ぐためランダム出題は行わない。

* モード1: 順唱 (Forward Span)
  * 目的: 音韻ループ・視空間スケッチパッドによる単純な情報保持（容量の拡張）。
  * ルール: 提示された数字の列を「表示されたそのままの順番」で回答する。
* モード2: 逆唱 (Backward Span)
  * 目的: 中央実行系による情報の単純操作と視空間マッピング。
  * ルール: 提示された数字の列を「最後から逆の順番」で回答する。
* モード3: 配列 (Sequencing)
  * 目的: 中央実行系による高度な情報操作（ソート処理）とダミーカードに対する抑制機能。
  * ルール: 提示された数字の列を、元の順番を無視して「一番小さい数から順番（昇順）」に回答する。

### 1.3 エラーレス学習と正解判定ロジック
誤った順序での入力をシステムが物理的（視覚・振動）に弾き、正しい記憶痕跡のみを強化する。
* 順唱: [提示順] と一致するカードのみ枠へのドロップを許可。
* 逆唱: [提示順の逆] と一致するカードのみ枠へのドロップを許可。
* 配列: [提示された数字を昇順にソートした順] と一致するカードのみ枠へのドロップを許可。ダミーカード（提示されていない数字）を選んだ場合は即座に弾く。

### 1.4 動的難易度調整 (DDA: 流暢性スコア方式)
「入力完了までの時間」と「エラー介入回数」から『流暢性スコア（Fluency Score）』を算出。直近5試行の移動平均に基づき、以下の3変数を組み合わせた「サブレベル」を昇降する。
1. 桁数 (2桁〜8桁)
2. 表示速度 (2.0秒 または 1.5秒)
3. ダミーカード (解答に不要なノイズ情報: 0〜2枚)

## 2. UI仕様 (User Interface Specifications)

### 2.1 記憶フェーズ（没入型UI）
視覚的ノイズを極限まで排除し、注意資源を数字の符号化に集中させる。
* 非表示要素: ステータスバー、スコア、メニューボタン類は完全フェードアウト。
* 表示要素: 画面中央（または空間マッピング用の特定位置）に表示される「超特大の数字」と、下部の「進捗ドット（●○○）」のみ。

### 2.2 回答フェーズ（ドラッグ＆ドロップUI）
テンキー入力を廃止し、高い視空間認知を直接的な情報操作に転用する。
* レイアウト: 
  * 上部: 回答をはめ込む「空のスロット（枠）」が左から順に並ぶ。
  * 中部: 「元の順番で」「逆の順番で」「小さい順に」という現在のモード指示を明記。
  * 下部: ランダムに配置された「数字カード」。サブレベルに応じ、提示されていないダミーカードが混ざる。
* インタラクション: 数字カードを指でドラッグし、上部の空スロットへドロップする。
* エラーレス介入の挙動: 
  * モードの正解判定ロジックに合致しないカードをドロップした場合、スロットは赤くならず、端末が軽く振動し、カードが元の位置に弾き返される。
  * 2回連続でエラーになった場合、正解のカードが薄くハイライトされ視覚的プロンプトを与える。

### 2.3 タッチ操作の最適化 (Touch Optimization)
ゲームとしての快適なレスポンスを確保するため、以下の最適化を適用している。
* イベント処理: 標準の `onClick` ではなく `onPointerDown` を使用し、タッチ開始時の即時反応を実現。
* ブラウザ挙動の制御: `touch-action: manipulation` を指定し、ピンチズームやダブルタップによる遅延を防止。
* Viewport設定: `user-scalable=no` により、モバイルブラウザのジェスチャー判定による操作妨害を最小化。

## 3. 技術スタック (Technical Stack)

* アーキテクチャ: PWA (Progressive Web App)
* フロントエンド: TypeScript + React
* 描画エンジン: PixiJS (WebGL) - ドラッグ＆ドロップ時の滑らかな吸着アニメーションや物理的挙動用
* 状態管理: Redux Toolkit（流暢性スコアや移動平均の高速計算）
* データ永続化: IndexedDB (Dexie.js)
