# 数字の逆さま記憶ゲーム - ワーキングメモリートレーニングアプリ仕様書 (Ver 2.0)

## 1. アプリ仕様 (Application Specifications)

### 1.1 概要
認知心理学の「数唱課題（逆唱）」を基盤とし、視空間認知を最大限に活用するワーキングメモリー（WM）トレーニングアプリ。エラーレス学習と動的難易度調整（DDA）を組み合わせ、認知的過負荷を防ぎながら記憶容量と実行機能を拡張する。

### 1.2 コアメカニクス
* タスク: ランダムに提示される数字の列を記憶し、「最後から逆の順番」で回答する。
* 記憶戦略の主軸: 空間的マッピング法（表示位置の分散）と音韻ループ（リハーサル音声）。※逆唱におけるチャンク化は認知的過負荷を避けるため廃止。
* エラーレス学習: 誤った順序での入力をシステムが物理的（視覚・振動）に弾き、正しい記憶痕跡のみを強化する。誤学習を徹底的に防ぐ。

### 1.3 動的難易度調整 (DDA: 流暢性スコア方式)
成否の二元論ではなく、「入力完了までの時間」と「エラー介入回数」から『流暢性スコア（Fluency Score）』を算出。直近5試行の移動平均に基づき、以下の3変数を組み合わせた「サブレベル」を昇降する。
1. 桁数 (2桁〜8桁)
2. 表示速度 (2.0秒 または 1.5秒)
3. ダミーカード (解答に不要なノイズ情報: 0〜2枚)

### 1.4 評価・フィードバックシステム
* WMI（ワーキングメモリー指標）の直接的な推定・表示は行わない。
* 同年代における統計的相対評価である「同年代パーセンタイル（上位◯%）」と、独自指標の「WMスコア（流暢性ベース）」を用いて成長を可視化する。
* 認知的疲労を検知した場合（スコアの急落時）は、強制的にクールダウンへ誘導するセーフティネットを実装。

## 2. UI仕様 (User Interface Specifications)

### 2.1 記憶フェーズ（没入型UI）
視覚的ノイズを極限まで排除し、注意資源を数字の符号化に集中させる。
* 非表示要素: ステータスバー、スコア、メニューボタン類は完全フェードアウト。
* 表示要素: 画面中央（または空間マッピング用の特定位置）に表示される「超特大の数字」と、下部の「進捗ドット（●○○）」のみ。
* 音声補助: 数字の表示に同期した音声読み上げ（設定でトグル可能）。

### 2.2 回答フェーズ（ドラッグ＆ドロップUI）
テンキー入力を廃止し、高い視空間認知を直接的な情報操作に転用する。
* レイアウト: 
  * 上部: 回答をはめ込む「空のスロット（枠）」が左から順に並ぶ。
  * 下部: ランダムに配置された「数字カード」（サブレベルによってはダミーカードが混ざる）。
* インタラクション: 数字カードを指でドラッグし、上部の空スロットへドロップする。
* エラーレス介入の挙動: 
  * 間違ったスロットにドロップした場合、スロットは赤くならず、端末が軽く振動し、カードが元の位置に弾き返される。
  * 2回連続でエラーになった場合、正解のカードが薄くハイライトされ視覚的プロンプトを与える。

### 2.3 成果表示フェーズ
* 「おしい！」「間違えた」といったネガティブな表示は行わず、自力クリア（完全正解）か、システム誘導あり（部分正解）かでスコアを加算。
* 今日の「最高パーセンタイル」と「WMスコアの伸び」をグラフィカルに表示。

## 3. 技術スタック (Technical Stack)

高頻度（毎日5〜10分）の利用を想定し、インストール不要かつネイティブライクな動作を実現するモダンWeb技術を採用する。

* アーキテクチャ: PWA (Progressive Web App) - オフライン動作およびホーム画面への追加をサポート。
* フロントエンド: TypeScript + Reactによる開発（コンポーネント指向によるUI状態管理）。
* 描画エンジン: PixiJS (WebGL) - ドラッグ＆ドロップ時の滑らかな吸着アニメーションや物理的挙動を60fpsで描画するため。
* 状態管理: Redux。流暢性スコアや移動平均をメモリ上で高速計算。
* データ永続化: IndexedDB (ブラウザ内DB) - オフライン時のプレイ記録を保存し、オンライン復帰時に同期。
* CI/CD: GitHub Actions - PWAのビルドおよびGitHub Pagesでのホスティング環境への自動デプロイ。

## 5. 実装状況 (Implementation Status) - 2026-03-15 現在

### 5.1 完了済み
*   **プロジェクト基盤**: Vite + React + TypeScript の構築。
*   **状態管理**: Redux Toolkit によるゲームフェーズ・スコア管理 (`store/slices/gameSlice.ts`)。
*   **データ永続化**: Dexie.js を用いた IndexedDB への試行ログ保存 (`db/db.ts`)。
*   **コアロジック**: 
    *   動的難易度調整 (DDA) アルゴリズムの実装 (`utils/dda.ts`)。
    *   流暢性スコア算出ロジックの実装 (`utils/scoring.ts`)。
*   **UI/UX**:
    *   PixiJS を使用したゲームキャンバス（記憶・回答フェーズ）の実装 (`components/GameCanvas.tsx`)。
    *   結果表示画面 (`components/ResultScreen.tsx`)。
*   **PWA**: Web Manifest の設定および Service Worker の生成設定。
*   **CI/CD**: GitHub Actions による GitHub Pages への自動デプロイワークフロー (`.github/workflows/deploy.yml`)。
