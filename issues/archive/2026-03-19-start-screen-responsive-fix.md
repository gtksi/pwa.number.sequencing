# スタート画面レイアウトの崩れ（文字切れ・重なり）の修正

## 概要
スマートフォンなどの画面幅が狭いデバイスにおいて、初期画面のタイトル「数字の記憶と操作」が枠からはみ出したり、文字が重なって表示されたりする不具合を修正しました。

## 原因
1.  **固定幅の指定**: `.start-screen` コンテナに `width: 450px` が指定されており、画面幅がそれ以下のモバイル端末で枠がはみ出していました。
2.  **大きな余白とフォントサイズ**: 大きな `padding` と `font-size` が組み合わさり、テキストの表示領域が不足していました。
3.  **文字間隔の負指定**: デスクトップ向けに `letter-spacing: -0.02em` が指定されていたため、フォントを小さくしたモバイル環境で文字が重なって見えていました。

## 修正内容

### 1. レスポンシブなコンテナ設計 (App.css)
`.start-screen` の指定を `width: 90%; max-width: 450px;` に変更し、画面幅に合わせて伸縮するようにしました。また `box-sizing: border-box` を追加し、パディングが幅に含まれるように調整しました。

### 2. モバイル向けメディアクエリの追加 (App.css)
画面幅が 480px 以下のデバイス向けに以下の調整を行いました：
-   **パディング**: `3rem` から `2rem 1.5rem` に縮小。
-   **タイトルフォント**: `2.5rem` から `1.8rem` に縮小。
-   **文字重なりの解消**: 重なりを防ぐため `letter-spacing: normal` を適用。
-   **ボタン**: タップしやすいよう、ボタン内のパディングとフォントサイズを微調整。

### 3. CSS互換性の向上
標準プロパティの `background-clip: text` を追加し、より多くのブラウザでタイトルグラデーションが正しく表示されるようにしました。

## 修正後の確認
ブラウザのモバイルエミュレーター（幅 375px/320px）にて、タイトルが枠内に収まり、文字の重なりも解消されていることを確認しました。
