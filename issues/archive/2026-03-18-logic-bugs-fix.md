# 論理バグの修正（タイムゾーンおよびアニメーション競合）

## 概要
コードベースの調査により判明した以下の2点の潜在的なバグを修正しました。

### 1. タイムゾーンによる記録のズレ（日本時間）
- **原因:** `session_id` の生成に `toISOString()` (UTC時間基準) を使用していたため、日本時間の午前9時以前にプレイしたデータが前日分として合算される問題がありました。
- **修正内容:** `Date` オブジェクトのローカル時間（`getFullYear` など）を使用して日付文字列を組み立てる処理に変更し、確実に端末のローカル日付が使われるように修正しました。
  - **対象ファイル:** `src/hooks/useGameLogic.ts`, `src/components/ResultScreen.tsx`

### 2. 不正解アニメーション中のドラッグ競合
- **原因:** スロットに間違ったカードを入れた際の「シェイクアニメーション（約20フレーム）」再生中、そのカードがタッチ可能状態のままでした。そのため、アニメーション再生中にそのカードをドラッグしようとすると、アニメーションの座標固定処理による上書きと指のドラッグが競合し、想定外の位置にワープするなどのバグが発生しました。
- **修正内容:** シェイクアニメーションの開始直前に `card.eventMode = 'none'` を設定してタッチ操作を無効化し、アニメーション終了後に `'static'` に戻すよう修正しました。
  - **対象ファイル:** `src/components/GameCanvas.tsx`
