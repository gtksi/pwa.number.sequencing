# 数字の記憶と操作 (Number Sequencing PWA) - Ver 3.0

ワーキングメモリー（WM）を段階的に強化するための、数唱課題（順唱・逆唱）および配列課題をベースとしたトレーニングアプリです。

## 🎮 トレーニングモード

1.  **順唱 (Forward Span)**: 表示された数字を「そのままの順番」で回答します。音韻ループの容量を広げます。
2.  **逆唱 (Backward Span)**: 表示された数字を「最後から逆の順番」で回答します。情報の操作と視空間マッピングを鍛えます。
3.  **配列 (Sequencing)**: 表示された数字を「小さい順（昇順）」に並び替えて回答します。高度な情報操作と、不要な情報の抑制機能を鍛えます。

## ✨ 特徴

-   **没入型UI**: 視覚的ノイズを排除したダークモード・デザイン。記憶フェーズでは数字の発光エフェクトにより集中を促します。
-   **空間マッピング**: 数字ごとに表示位置を固定（3x3グリッド）することで、視覚的な位置情報と数字を紐付けた記憶をサポートします（設定でON/OFF可能）。
-   **エラーレス学習**: 正解ではないカードをタップした際のシェイクアニメーションにより、誤った記憶痕跡を残さない学習をサポート。2回連続ミスでヒントが表示されます。
-   **直感的なUI操作**: 各種モバイル端末（iOS/Android）で確実に動作するよう、想起フェーズにはドラッグ操作ではなく、誤操作の少ないタップ方式を採用。
-   **動的難易度調整 (DDA)**: 回答速度と正確さから算出される「流暢性スコア」に基づき、桁数・表示速度・ダミーカード数が自動で調整されます。
-   **音声読み上げ**: 数字の表示に合わせて合成音声が読み上げを行います（設定でON/OFF可能）。

## 🕹 技術スタック

-   **Frontend**: React + TypeScript
-   **Rendering**: PixiJS (記憶フェーズの滑らかなアニメーション) + React DOM (想起フェーズの確実な操作)
-   **State Management**: Redux Toolkit
-   **Database**: IndexedDB (Dexie.js) - 試行ログとユーザー統計の永続化
-   **PWA**: Vite PWA Plugin - オフラインプレイ・ホーム画面追加に対応

## 🛠 実行方法

